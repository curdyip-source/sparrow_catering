# Changelog

Все заметные изменения проекта фиксируются в этом файле.
Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версионирование — [SemVer](https://semver.org/lang/ru/).

## [1.0.0] — 2026-08-15

Первый релиз. Механика приложения зафиксирована и считается стабильной.

### Публичная часть

- Лендинг SP.ARROW с калькулятором заявки и формой лида (`POST /api/leads`).
- Публичные коэффициенты расчета (`GET /api/pricing/default`).
- Экспорт коммерческого предложения в PDF.

### Админка

- Первичная инициализация: статус bootstrap и создание первого администратора.
- Авторизация администратора, профиль текущего пользователя.
- Редактирование коэффициентов расчета.
- Справочник компаний (CRUD).
- Гости и их предпочтения (CRUD).
- Заказы: создание, учет расходов, удаление.

### Склад

- Каталог табаков с карточкой товара и остатками.
- Регистр остатков и журнал движений по номенклатуре.
- Документы склада: приход, списание, начальный остаток; создание, редактирование, удаление.
- Инвентаризация: сессии, построчный ввод, формирование документов и проведение.

### Инфраструктура

- Docker Compose: backend (FastAPI), frontend (React + Vite), PostgreSQL, Redis, Celery.
- Собственный блок портов 42100–42109, чтобы проект не конфликтовал с другими локальными сервисами.
- Миграции Alembic, тесты backend, CI на GitHub Actions.
- git-crypt для `.volume` и `.docs`, автоматический бэкап БД.
